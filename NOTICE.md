# Attribution and provenance

This is an independent Windows integration of [steelbrain/reims-vgpu](https://github.com/steelbrain/reims-vgpu), [steelbrain/metal2vulkan](https://github.com/steelbrain/metal2vulkan) and [steelbrain/qemu-reims-vgpu](https://github.com/steelbrain/qemu-reims-vgpu). It is not an official upstream release.

Windows platform implementations and toolchain conventions also derive from [tqmane/reims-vgpu](https://github.com/tqmane/reims-vgpu) and [tqmane/qemu-reims-vgpu](https://github.com/tqmane/qemu-reims-vgpu). All original authors retain their copyrights. Upstream source notices remain intact when patches are applied. See sources.json for base revisions and patch checksums.

The patches include the existing local Windows port, clock correction, WHPX diagnostic controls, and subsequent shared-section guest-memory integration. Local source endpoints were Reims 9d57adfb5, QEMU bd00ca633c and metal2vulkan 3bfe1972. The Reims submodule pointer is deliberately excluded: QEMU is fetched independently and patched separately.

Reims and metal2vulkan permit GPL-2.0-or-later OR LGPL-3.0-or-later; QEMU retains its per-file licensing. The licenses directory contains original notices and full texts. Cargo/MSYS2 dependencies and OpenCore/EDK II retain their own licenses. Release v1.0 distributes a Windows runtime and a self-contained .NET manager. The runtime source archive supplies patched QEMU/Reims/metal2vulkan sources, Cargo dependencies, exact MSYS2 source packages with build recipes, and matching SeaBIOS/iPXE sources. Runtime packages retain dependency license notices. Manager source and build/packaging instructions are in this repository at the release tag. PowerShell is downloaded separately from its official Microsoft release and retains its notices.

Modifications were prepared with AI assistance. This repository is a downstream distribution, not a submission to QEMU upstream. The screenshot was supplied and approved for publication by the repository owner.

Prerelease 1.1.0-pre.1 adds adaptive display and the Windows build of [steelbrain/reims-util](https://github.com/steelbrain/reims-util) at `84e5c98ae7fa6b0b68e7be690525dda29697ab34`, distributed under GPL-2.0-or-later (its dual-license alternative remains available). Its macserial-derived code retains OpenCorePkg's BSD-3-Clause notices. The matching Reims guest prebuilts, Graft and graphics ROM retain their upstream licenses; Graft's notices are included separately. The runtime source ZIP includes reims-util sources and combined vendored dependencies in addition to the patched graphics stack. OpenCore, OVMF and Apple recovery media are downloaded by the user-side helper, not copied from the developer's VM or distributed in the release. Downloaded OpenCore/OVMF remain subject to their original licenses; no developer machine identity or VM disk is included.
