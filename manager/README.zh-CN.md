# Weims Manager 1.0.1 使用说明

> **开发状态：** 交互软件目前尚不完善，正在持续开发。部分准备仍需手动完成，完整恢复安装流程尚未经过端到端验证。请参阅[首次安装指南（英文）](../docs/first-install.md)。

这是一版 Windows 桌面配置器，采用 macOS“系统设置”风格。软件负责虚拟机配置与恢复安装准备，Reims 显示窗口独立运行。

## 安装与自动准备环境

从 [v1.0.1 发布页](https://github.com/H0yeR404/weims-vgpu/releases/tag/v1.0.1) 下载 `Weims-Manager-1.0.1-Setup-x64.exe`。安装包内置 .NET，按当前用户安装；也可使用便携 ZIP。要求 Windows 10 2004 或更新的 x64 系统，以及兼容的 CPU 虚拟化与显卡。

**首次启动默认英文，不跟随系统语言。** 在侧栏选择“简体中文”后关闭并重新打开管理器即可应用；之后记住所选语言。关闭管理器不会关闭虚拟机。

进入 **Runtime / 运行环境**，点击 **Check environment / 检测环境**，再点击 **Prepare / Retry / 一键准备 / 重试**。软件下载本项目固定版本 QEMU/Reims 运行包，验证 SHA256 后解压；缺少 PowerShell 7 时，自动下载微软官方便携版。此方式不需要安装 MSYS2 或编译工具。支持进度显示、取消和重试，运行验证成功后才保存新路径。重试使用独立目录，不覆盖使用中的运行环境，旧目录会保留。

检测涵盖系统架构、固件虚拟化、WHPX、支持 `VK_EXT_external_memory_host` 的 Vulkan GPU、运行程序及 PowerShell。检测通过不等于所有 macOS 版本均能启动。Windows 功能按钮可打开系统设置以启用 Windows 虚拟机监控程序平台，可能需要管理员确认及重启；BIOS 虚拟化和显卡驱动由用户按提示处理，软件不会自动重启或更改安全设置。

配置与下载组件保存在 `%LOCALAPPDATA%/Weims/Manager`。卸载仅删除软件，不删除虚拟机、设置或下载的运行环境。恢复镜像、配置好的 OpenCore、OVMF 和 ROM 仍需自行提供。安装包暂未做 Authenticode 签名。

## 启动与导入

运行构建目录中的 `Weims.Manager.exe`，可使用 `--repo <weims-vgpu目录>` 指定运行组件所在仓库。便携版本需要保留整个程序目录，不能单独移动 EXE。应用配置保存在 `%LOCALAPPDATA%\Weims\Manager`。

点击“导入虚拟机”，选择已有新通道虚拟机的 `state\config.json`。导入仅登记路径，不复制或改写系统盘。旧通道虚拟机应先按仓库复现指南完成 OpenCore 驱动迁移。现有配置中的其他字段会保留。

“运行环境”页面选择 QEMU、MSYS2 的 `ucrt64\bin` 和 QEMU 的 `pc-bios` 目录，再检查保存。QEMU 目录内需要配套的 `qemu-img.exe` 和 `reims_vgpu_c.dll`。SMC OSK 已自动配置，无需填写。

## SMC OSK 自动配置

当前 Intel macOS/QEMU 方案使用固定的 SMC OSK，管理器已内置默认值，不需要用户查询或填写。它不是 Apple ID 密码或每台机器独有的序列号，也不代表其他 CPU 架构或任意 macOS 版本均受支持。

高级用户仍可在启动管理器前通过 `WEIMS_OSK` 环境变量覆盖默认值。未设置或为空时使用默认值；非空覆盖值须满足 64 个 ASCII 字符的格式要求。命令预览和日志继续脱敏，QEMU 通过进程参数接收实际值。

## 配置显示与输入

“显示与输入”提供客户机分辨率、无边框全屏和鼠标自由移出开关。更改在虚拟机停止后保存，下次启动生效。客户机分辨率与宿主窗口大小独立；普通窗口可拖动边缘调整大小，并保持画面比例。当前 Tahoe 路径限制宽度不超过 2048，推荐 1920×1080。

自动准备的运行包已包含自由鼠标输入扩展。手动构建时：运行 `pwsh -File manager/build-input.ps1` 后选择 `build\manager-runtime\qemu-system-x86_64.exe`。程序会校验对应 DLL；不支持时开关禁用。开启后不再因点击画面而锁住鼠标，宿主系统快捷键保留；关闭后沿用捕获模式，使用 Ctrl+Alt+Win 或 Ctrl+Alt+Home 释放。这不包含剪贴板共享或文件拖放。

“硬件与网络”可修改 CPU、内存、SSH 转发端口及 QMP 管理端口。不同虚拟机需要不同端口，均仅监听本机。磁盘容量在创建向导中设置；此版不对已有系统盘进行扩容。

## 从恢复镜像创建

安装向导接受 `BaseSystem.dmg` 或原始 `.img`，不接受完整 ISO。还需提供已经配置好新通道驱动的 OpenCore 原始 FAT 镜像、匹配的 OVMF CODE/VARS 和 Reims ROM。如何准备这些文件见 [复现指南](../docs/reproduce.md)。不要使用正在运行的虚拟机的可写固件。

选择新的存放目录和系统盘容量后，向导调用 `qemu-img` 检查、展开恢复镜像，并创建稀疏 QCOW2 系统盘与固件副本。不会覆盖已有目录。取消或失败时保留临时准备目录供检查，源文件不变。镜像头检查只能排除明显错误，不能保证任意镜像都能安装。

准备完成后，手动启动虚拟机。在 OpenCore 选择恢复系统，必要时按空格显示辅助项目。在磁盘工具中仅格式化新建空白系统盘为 GUID/APFS，再联网安装。安装完成并关机后，取消“下次启动时挂载恢复镜像”并保存。

## 关机与诊断

“正常关机”发送 ACPI 关机请求；macOS 没有响应时，请使用苹果菜单关机。“强制停止”经确认后退出 QEMU，可能丢失未保存的数据。关闭管理器不会关闭虚拟机。

“诊断与日志”可预览脱敏启动参数、读取日志尾部或打开日志目录。状态未知时程序会锁定配置和启动操作，避免误操作其他实例。

## 本版验证边界

已通过 20 项核心检查、7 项 WPF 界面检查、9 项真实工具集成检查和 98 项窗口后端测试。界面已检查六个页面、安装表单及最小窗口尺寸。集成验证使用临时合成镜像和不加载客户机系统的 QEMU，不影响现有虚拟机。

尚未用这套向导完成完整 macOS 恢复安装，也未在实际 macOS 桌面人工验收自由鼠标。高对比度、屏幕阅读器与长时间运行仍待验证。具体构建、测试和许可证信息见 [英文开发说明](README.md)。
