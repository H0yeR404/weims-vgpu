# Weims Manager 1.2.1

正式リリースで、Latest としてマークされています。Windows の GUI と CLI、macOS 用の Guest Tools、ランタイム 1.2.1 を含みます。

## 新機能

- **Windows キーが Command として働きます。** フリーポインターがオンのとき、ポインターが VM の画面内にある間は、Windows キーが Command として macOS に届きます。ポインターが画面の外にあるときは、これまでどおり Windows のキーです。Alt+Tab などほかの Windows ショートカットは Windows に残ります。
- **VM の実行中にフルスクリーンを切り替えられます。** VM のウィンドウで **Ctrl+Alt+Enter** を押すか、Manager の **Full screen / window** をクリックします。VM を再起動する必要はありません。フルスクリーンでは、ポインターを画面上部の中央に置くと小さなバーが現れ、ウィンドウの最小化やウィンドウ表示への復帰ができます。
- **Mac の機種。** macOS は VM を iMac（27 インチ、2020）または MacBook Pro（16 インチ、2019）として扱います。**Create VM** で選び、後から VM を停止した状態で **Hardware & Network → Mac model** で変更するか、`Weims.Cli model --model MacBookPro16,1` を使います。グラフィックスとハードウェアビデオデコードはどちらの機種でも同じように動作します。

機種を変えるとシリアル番号も変わるため、iCloud、iMessage、App Store には新しいデバイスとして見えます。変更の前に macOS で Apple Account からサインアウトし、変更後にサインインし直してください。ディスク、システム UUID、ネットワークアドレスは変わらず、元の機種に戻すと以前のシリアル番号に戻ります。

## インストールと更新

`Weims-Manager-1.2.1-Setup-x64.exe` をダウンロードするか、`Weims-Manager-1.2.1-win-x64.zip` を展開します。

1.1.0、1.1.1、1.2.0 は **Software updates → Check for updates → Update now** で更新できます。プレビュー版 1.2.0-pre.1 にもこのリリースが表示されます。1.0.1 は一度だけ手動でインストーラーをダウンロードしてください。先に VM とほかの Manager のウィンドウを閉じてください。

**更新後はランタイムを更新してください。** 上の 3 つの機能はランタイム 1.2.1 に入っています。更新後、Manager の上部に通知が表示されるので、**Update runtime now** をクリックします。1.2.0 のランタイムのままでも VM はこれまでどおり起動しますが、新機能は使えません。1.2.0 より古いランタイムは更新が必須で、更新するまで VM は起動できません。ランタイムの場所を自分で指定した場合は、自分で置き換えてください。

既存の VM を作り直す必要はなく、機種は元の iMac のままです。

## 既知の問題

- VM のウィンドウへのファイルのドラッグ、ウィンドウからのドラッグはできません。このバージョンでは、USB デバイスのパススルーはまだできません。
- どの PC でも、macOS は GPU を「AMD - 」とその PC の GPU 名で表示します。これはランタイムのグラフィックスドライバーが意図して行っていることです。macOS と一部のアプリは、名前に含まれるベンダーによって処理を選ぶためです。

## 検証

自動テスト：コア 138 項目、WPF インターフェース 88 項目、更新の選択 31 項目、パッチを当てたウィンドウコードのテスト 127 件。

実際の VM（macOS 26.7.2、NVIDIA GPU を搭載した Windows 11 ホスト 1 台）：Windows キーとフルスクリーンは手動で使用しました。Mac の各機種をネットワークなしで 1 回ずつ起動し、グラフィックスドライバー、Metal 3、H.264 と HEVC のハードウェアデコードが同じであること、デコードした全フレームが ffmpeg の結果と一致することを確認しました。機種の変更は CLI で行いました。Manager のボタンは同じコードを実行しますが、手動ではクリックしていません。未テスト：MacBook Pro としてリカバリから macOS をインストールすること、いずれかの機種で Apple Account にサインインすること、複数ディスプレイ、Intel と AMD の GPU。詳細は[検証記録](validation.md)にあります。

ランタイムの ZIP と対応するソースアーカイブを添付しており、すべてのファイルに SHA256 チェックサムがあります。
