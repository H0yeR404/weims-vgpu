# Weims Manager 1.1.0

基于 1.1.0-pre.2 的正式版，标记为 Latest，包含 Windows GUI 与 CLI。

## 更新内容

- 侧栏新增浅色／深色切换，无需重启，自动记住选择。默认仍为英文和浅色。
- 切换外观保留当前页面及未保存输入，已打开的安装向导同步更新。Windows 高对比度设置优先。
- 包含 pre.2 的一键运行环境准备、校验后软件更新、更新说明和中英文即时切换。
- 包含 pre.1 的恢复安装自动准备与客户机自适应分辨率。
- GUI 和 CLI 都读取更新器保留的设置目录，复用已有预览版配置；全新安装使用正式版设置目录。

## 安装与升级

下载 `Weims-Manager-1.1.0-Setup-x64.exe`，或解压 `Weims-Manager-1.1.0-win-x64.zip`。两者均包含 GUI 与 CLI，无需另装 .NET，安装包和应用保留 Weims 图标。

pre.2 用户可选择 **软件更新 → 检查更新 → 一键更新**。安装前请关闭虚拟机及其他 Manager 窗口。1.0.1 和 pre.1 需手动下载安装一次。1.1.0 使用正式版 Weims Manager 的安装身份与应用目录；旧 Preview 快捷方式不会自动删除，升级后请使用正式版快捷方式。

便携版通过更新器升级后会安装到当前用户的应用目录，保留所选设置目录。未显式指定或经更新器保留时，优先复用已有 `%LOCALAPPDATA%\Weims\Manager-Preview`，否则使用 `%LOCALAPPDATA%\Weims\Manager`。GUI 和 CLI 均接受 `--data-dir`。不会转换或替换虚拟机磁盘。

## 运行库与已知问题

QEMU/Reims 图形运行库没有变化，仍固定为 [v1.1.0-pre.1](https://github.com/H0yeR404/weims-vgpu/releases/tag/v1.1.0-pre.1)，对应运行库 ZIP 和源码归档仍在该页面。更新管理器不会替换已有有效运行库。

**虚拟机仍可能卡死，包括调整分辨率时，目前仍在排查。** 正式发布不代表这些问题已经修复。[Issue #2](https://github.com/H0yeR404/weims-vgpu/issues/2) 报告了 Intel Arc 140T 的图形格式错误及 macOS 初始化卡死，Intel Arc 兼容性尚未充分验证。跨设备兼容性、全新恢复安装到桌面的完整流程及长期稳定性仍未完成验证。不包含剪贴板共享、文件共享或跨系统文件拖拽。

此次改动集中在管理器外观和发布通道，没有修改客户机图形实现。请备份重要虚拟机数据。

## 验证

WPF 检查覆盖即时主题／语言切换、设置重载、可编辑选择框、未保存输入、两种外观、最小窗口和安装向导。Core 检查覆盖预览版／正式版／自定义设置目录选择。更新选择检查覆盖 pre.2 升级到 1.1.0。安装交接测试模拟进程和安装边界，不宣称已验证真实覆盖安装。发布附件包含 SHA256 校验清单。
