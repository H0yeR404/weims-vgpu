# Weims Manager 1.2.0

正式版，标记为 Latest，包含 Windows 图形界面和命令行、macOS 端的 Guest Tools，以及新的运行组件。

## 新内容

- **运行组件 1.2.0，直接基于上游构建。** 上游 [Reims vGPU](https://github.com/steelbrain/reims-vgpu) 现在自己支持 Windows 主机，本项目不再维护自己的移植，只在其上加一个窗口补丁。它带来的变化：macOS 有声音输出；macOS 的分辨率跟随窗口，固定分辨率和兼容模式不再提供；关闭虚拟机或关机后 QEMU 立即退出；显卡需要支持 Vulkan 1.3。
- **Guest Tools：剪贴板。** 虚拟机窗口在前台时，在一边复制的文本可以在另一边粘贴。文本上限 4 MiB。
- **Guest Tools：复制粘贴文件。** 在资源管理器里复制文件或文件夹，到访达里粘贴，不限大小；在访达里复制，回到 Windows 粘贴，一次最多 256 MiB。
- **Guest Tools：共享文件夹。** 选择这台电脑上的文件夹，它会挂载到 macOS 里，可设为只读。不创建 Windows 共享，不需要管理员权限，不动防火墙。
- **更新频道。** 在**软件更新**里选择只接收正式版，或预览版和正式版都接收。
- 管理器、命令行和 Guest Tools 的主机端进程基于 .NET 10 构建，安装包自带运行时。

Guest Tools 的安装和各项功能的细节见 [Manager 说明](../manager/README.zh-CN.md)。

## 安装与升级

下载 `Weims-Manager-1.2.0-Setup-x64.exe`，或解压 `Weims-Manager-1.2.0-win-x64.zip`。

1.1.0 和 1.1.1 用户可选择**软件更新 → 检查更新 → 一键更新**；预览版 1.2.0-pre.1 也会收到它。1.0.1 需手动下载安装一次。安装前请关闭虚拟机和其他 Manager 窗口。

**升级后必须更新运行组件。** 这个版本的管理器不能使用旧的运行组件。升级后管理器顶部会出现一条提示，点击**立即更新运行组件**，下载约 95 MB。在此之前虚拟机无法启动；点击启动时管理器也会询问并替你更新。自行指定运行环境路径的用户需要自己换成新的运行组件。

已有虚拟机不用重建。用早先版本创建的虚拟机，第一次启动时会重新制作引导镜像，换上新运行组件的图形驱动，Mac 身份保持不变；原镜像保留在旁边，名为 `OpenCore.img.previous`。

已经装过 Guest Tools 的虚拟机，macOS 里的 Guest Tools 会在连上新管理器后自动更新。

## 已知问题

- 使用中虚拟机可能卡死，仍在排查。
- Intel 显卡（[Issue #2](https://github.com/H0yeR404/weims-vgpu/issues/2)）没有在新运行组件上验证过。
- 不支持把文件拖进或拖出虚拟机窗口，不支持 USB 设备直通。

## 验证

自动化：核心 120 项、Guest Tools 主机端进程 343 项、WPF 85 项、更新选择 31 项。

真实虚拟机（macOS 26.7.2，一台带 NVIDIA 显卡的 Windows 11 主机）：启动、图形、自由鼠标、窗口缩放、声音、关机；Guest Tools 的文本和文件复制粘贴、共享文件夹；从运行组件 1.2.0-pre.1 换到打包的 1.2.0。各项测了什么、没测什么见[验证记录](validation.md)。

运行组件 ZIP 和对应的源码包随附，所有文件均附 SHA256 校验值。
