# Weims Manager 1.2.1

正式版，标记为 Latest。包含 Windows 图形界面和命令行、macOS 端的 Guest Tools，以及运行组件 1.2.1。

## 新增内容

- **Windows 键相当于 Command。** 开启自由鼠标时，鼠标在虚拟机画面内按 Windows 键，macOS 收到的是 Command；鼠标移出画面后，这个键照常归 Windows。Alt+Tab 等其他 Windows 快捷键不受影响。
- **运行中切换全屏。** 在虚拟机窗口里按 **Ctrl+Alt+Enter**，或在管理器里点击**全屏 / 窗口**，不用重启虚拟机。全屏时把鼠标停在屏幕顶部中间，会出现一个小工具条，可以最小化或返回窗口。
- **Mac 机型。** macOS 会把虚拟机当作 iMac（27 英寸，2020）或 MacBook Pro（16 英寸，2019）。在**创建虚拟机**时选择；以后在虚拟机关机状态下到**硬件与网络 → Mac 机型**更换，或使用 `Weims.Cli model --model MacBookPro16,1`。两种机型的图形加速和视频硬件解码相同。

换机型会换序列号，iCloud、iMessage 和 App Store 会把它当作新设备。请先在 macOS 里退出 Apple 账户，换好后再登录。磁盘、系统 UUID 和网卡地址不变，切回某个机型时会用回它原来的序列号。

## 安装与升级

下载 `Weims-Manager-1.2.1-Setup-x64.exe`，或解压 `Weims-Manager-1.2.1-win-x64.zip`。

1.1.0、1.1.1 和 1.2.0 可以通过**软件更新 → 检查更新 → 一键更新**升级，预览版 1.2.0-pre.1 也会收到本版本。1.0.1 用户需手动下载安装一次。升级前请关闭虚拟机和其他管理器窗口。

**升级后请更新运行组件。** 上面三项功能在运行组件 1.2.1 里。升级后管理器顶部会出现提示，点击**立即更新运行组件**。继续使用 1.2.0 的运行组件时，虚拟机照常启动，只是没有新功能。早于 1.2.0 的运行组件必须更新，更新之前虚拟机无法启动。自行指定位置的运行组件需要自己替换。

已有的虚拟机不用重新创建，机型保持为原来的 iMac。

## 已知问题

- 不能把文件拖入或拖出虚拟机窗口，此版本暂时不能直通 USB 设备。
- 在任何电脑上，macOS 显示的显卡名称都是“AMD - ”加上这台电脑的显卡名。这是运行组件的图形驱动有意为之：macOS 和一些应用会按名称里的厂商选择处理方式。

## 验证

自动测试：核心 138 项，WPF 界面 88 项，更新选择 31 项，以及窗口补丁代码的 127 项测试。

真实虚拟机（macOS 26.7.2，一台带 NVIDIA 显卡的 Windows 11 主机）：Windows 键和全屏经过手动使用；两种 Mac 机型各在断网状态下启动一次，图形驱动、Metal 3、H.264 和 HEVC 硬件解码相同，解码出的每一帧都与 ffmpeg 的结果比对过。机型是用命令行更换的；管理器里的按钮运行同一段代码，没有手动点击过。未测试：以 MacBook Pro 身份从恢复环境安装 macOS、在任一机型下登录 Apple 账户、多显示器、Intel 和 AMD 显卡。详情见[验证记录](validation.md)。

运行组件 ZIP 及其对应的源码包已随附，每个文件都有 SHA256 校验值。
