# Weims Manager 1.1.0

1.1.0-pre.2 を基にした正式版です。Latest として公開し、Windows GUI と CLI を同梱します。

## 変更内容

- サイドバーにライト／ダーク切り替えを追加しました。再起動せず適用し、選択を保存します。既定は英語とライトテーマです。
- 現在のページと未保存の入力を保持し、開いているセットアップ画面も切り替わります。Windows のハイコントラスト設定が優先されます。
- pre.2 のワンクリック実行環境準備、検証付きソフトウェア更新、リリースノート、英語／中国語の即時切り替えを含みます。
- pre.1 の復旧インストール自動準備とゲスト解像度の自動調整を含みます。
- GUI と CLI は更新時に保持した設定ディレクトリを使用します。既存プレビューの設定を再利用し、新規インストールでは正式版の設定先を使用します。

## インストールと更新

`Weims-Manager-1.1.0-Setup-x64.exe` を実行するか、`Weims-Manager-1.1.0-win-x64.zip` を展開します。どちらも GUI と CLI を含み、別途 .NET は不要です。インストーラーとアプリは Weims アイコンを使用します。

pre.2 は **Software updates → Check for updates → Update now** から更新できます。インストール前に VM とほかの Manager を閉じてください。1.0.1 と pre.1 は手動インストールが必要です。1.1.0 は正式版のアプリ ID とフォルダーを使用します。古い Preview ショートカットは削除されないため、更新後は正式版を起動してください。

ポータブル版の更新はユーザー用アプリフォルダーへのインストールになります。選択した設定ディレクトリは保持されます。明示指定や更新時の指定がなければ、既存の `%LOCALAPPDATA%\Weims\Manager-Preview` を優先し、それがなければ `%LOCALAPPDATA%\Weims\Manager` を使用します。GUI と CLI は `--data-dir` に対応します。VM ディスクは変換・置換しません。

## ランタイムと既知の問題

QEMU/Reims ランタイムは変更せず、[v1.1.0-pre.1](https://github.com/H0yeR404/weims-vgpu/releases/tag/v1.1.0-pre.1) に固定しています。ランタイム ZIP と対応ソースは同リリースにあります。有効な既存ランタイムは Manager 更新で置き換えません。

**解像度変更時などに VM がフリーズする可能性は引き続きあります。調査中です。** 正式リリースは修正済みを意味しません。[Issue #2](https://github.com/H0yeR404/weims-vgpu/issues/2) では Intel Arc 140T のグラフィックス形式エラーと macOS 初期設定中のフリーズが報告されており、Intel Arc の互換性は十分に検証されていません。幅広いハードウェア、復旧からデスクトップまでの完全な新規インストール、長期安定性も未検証です。クリップボード共有、ファイル共有、システム間のファイルドラッグは含みません。

今回の変更は Manager の外観とリリース区分が中心で、ゲストのグラフィックス実装は変更しません。重要な VM データはバックアップしてください。

## 検証

WPF テストは即時テーマ／言語切り替え、設定の再読込、編集可能な選択欄、未保存入力、両テーマ、最小ウィンドウとセットアップ画面を確認します。Core テストはプレビュー／正式版／カスタム設定先の選択を確認します。更新選択は pre.2 から 1.1.0 への更新を確認します。インストーラー引き継ぎテストはプロセスとインストール境界を模擬しており、実際の上書き更新を検証済みとはしていません。SHA256 チェックサムを添付します。
