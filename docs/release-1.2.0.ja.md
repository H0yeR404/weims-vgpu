# Weims Manager 1.2.0

正式版で、Latest に設定されています。Windows の GUI と CLI、macOS 用の Guest Tools、新しいランタイムを含みます。

## 新機能

- **ランタイム 1.2.0：上流から直接ビルド。** 上流の [Reims vGPU](https://github.com/steelbrain/reims-vgpu) が Windows ホストに対応したため、本プロジェクトは独自の移植を持たず、ウィンドウ用のパッチを 1 つ加えるだけになりました。変わる点：macOS から音が出ます。macOS の解像度はウィンドウに追従し、固定解像度モードと互換モードはなくなりました。VM を閉じるかシャットダウンすると QEMU がすぐに終了します。GPU は Vulkan 1.3 に対応している必要があります。
- **Guest Tools：クリップボード。** VM のウィンドウが前面にある間、片方でコピーしたテキストをもう片方で貼り付けられます。4 MiB までです。
- **Guest Tools：ファイルのコピー＆ペースト。** エクスプローラーでコピーしたファイルやフォルダーを Finder で貼り付けられます（サイズ制限なし）。Finder でコピーして Windows で貼り付けることもできます（1 回につき 256 MiB まで）。
- **Guest Tools：共有フォルダー。** この PC のフォルダーを選ぶと macOS にマウントされます。読み取り専用にもできます。Windows の共有は作成せず、管理者権限は不要で、ファイアウォールにも触れません。
- **更新チャンネル。** **Software updates** で、正式版のみか、プレビュー版と正式版の両方かを選べます。
- Manager、CLI、Guest Tools のホスト側プロセスは .NET 10 でビルドされています。パッケージに必要なランタイムが含まれます。

Guest Tools のインストール方法と各機能の詳細は [Manager の README](../manager/README.ja.md) にあります。

## インストールと更新

`Weims-Manager-1.2.0-Setup-x64.exe` をダウンロードするか、`Weims-Manager-1.2.0-win-x64.zip` を展開します。

1.1.0 と 1.1.1 のユーザーは **Software updates → Check for updates → Update now** を使えます。プレビュー版 1.2.0-pre.1 にもこのリリースが表示されます。1.0.1 のユーザーは一度だけ手動でインストールします。先に VM とほかの Manager ウィンドウを閉じてください。

**更新後はランタイムの更新が必須です。** このバージョンの Manager は以前のランタイムを使えません。更新後、Manager の上部に通知が表示されるので、**Update runtime now** をクリックしてください（約 95 MB）。それまで VM は起動できません。Start をクリックしたときにも Manager が確認し、代わりに更新します。ランタイムの場所を自分で指定している場合は、自分で置き換えてください。

既存の VM を作り直す必要はありません。以前のバージョンで作成した VM は、最初の起動時にブートイメージを作り直し、新しいランタイムのグラフィックスドライバーを入れます。Mac の識別情報は変わらず、元のイメージは `OpenCore.img.previous` として残ります。

Guest Tools をすでにインストールしている場合は、新しい Manager に接続すると macOS 側で自動的に更新されます。

## 既知の問題

- 使用中に VM がフリーズすることがあります。引き続き調査中です。
- Intel GPU（[Issue #2](https://github.com/H0yeR404/weims-vgpu/issues/2)）は新しいランタイムでは確認していません。
- VM のウィンドウへのファイルのドラッグ＆ドロップと、USB デバイスのパススルーには対応していません。

## 検証

自動テスト：コア 120 件、Guest Tools のホスト側 343 件、WPF 85 件、更新の選択 31 件。

実際の VM（macOS 26.7.2、NVIDIA GPU を搭載した Windows 11 ホスト 1 台）：起動、描画、自由なポインター移動、ウィンドウのサイズ変更、音声出力、シャットダウン。Guest Tools のテキストとファイルのコピー＆ペースト、共有フォルダー。ランタイム 1.2.0-pre.1 からパッケージ版 1.2.0 への移行。テストした項目としていない項目は[検証記録](validation.md)にあります。

ランタイムの ZIP と対応するソースアーカイブを添付しており、すべてのファイルに SHA256 チェックサムがあります。
